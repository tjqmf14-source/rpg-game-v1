# RELIC BOUND Playtest Checklist

각 빌드에서 아래 순서로 직접 확인합니다.
문제가 있으면 **재현 순서 + 화면 캡처 + 예상 동작/실제 동작**을 기록합니다.

- [ ] WASD/방향키 이동이 정상이다.
- [ ] 건물과 맵 경계를 통과하지 않는다.
- [ ] 로완에게 E로 대화/영입할 수 있다.
- [ ] 미라에게 E로 대화/영입할 수 있다.

- [ ] 세 종류를 각각 1마리 처치한 뒤 아델에게 돌아가면 퀘스트가 완료된다.
- [ ] 완료 보상은 Gold 25 + 바람의 부적 1개이며 반복 대화로 중복 지급되지 않는다.
- [ ] 숫자 1~4로 해금된 파티원을 전환할 수 있다.
- [ ] 동쪽 출구로 이동하면 초원으로 전환된다.
- [ ] 초원에서 슬라임/고블린/스켈레톤을 확인할 수 있다.
- [ ] 적이 바위와 월드 경계를 무시하고 통과하지 않는다.
- [ ] J 또는 좌클릭 공격이 전방의 실제 범위 안 적에게만 적중한다.
- [ ] 공격 범위 밖의 적은 피해를 받지 않는다.
- [ ] K/Space 회피 중에는 피해를 받지 않는다.
- [ ] 적 공격을 받으면 HP가 감소한다.
- [ ] 적 처치 시 XP/Gold/드롭이 반영된다.
- [ ] P 파티 UI가 열린다.
- [ ] I 인벤토리 UI가 열린다.
- [ ] C 도감 UI가 열린다.
- [ ] F5 저장 후 위치/진행도가 기록된다.
- [ ] 다른 위치로 이동한 뒤 F9 로드 시 저장 상태로 돌아간다.
- [ ] 초원에서 사망하면 시작 마을 안전 지점으로 복귀한다.
- [ ] 사망 후 HP가 최대치로 복구된다.
- [ ] 마을 ↔ 초원 전환을 여러 차례 반복해도 중복 맵/오브젝트가 생기지 않는다.

## 빌드 판정

### PASS
진행을 막는 오류가 없고 위 항목이 모두 정상.

### CONDITIONAL PASS
사소한 UI/그래픽 문제만 있고 게임 진행에는 영향 없음.

### FAIL
다음 중 하나라도 발생:

- 크래시
- 저장 데이터 손상
- 맵 이동 불가
- 캐릭터 이동 불가
- 전투 불가
- 사망 후 진행 불가
- 반복 동작으로 오브젝트가 중복되거나 성능이 급격히 저하됨

FAIL 빌드는 다음 기능 개발 전에 먼저 수정합니다.
