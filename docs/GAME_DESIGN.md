# RELIC BOUND — Game Design Baseline

## 장르

16×16 픽셀 아트 기반 2D 탑다운 판타지 수집형 액션 RPG.

## 핵심 경험

플레이어는 작은 판타지 세계를 직접 탐험하면서 영웅, 몬스터 도감, 장비, 유물을 수집한다.
수집 자체가 목적이 아니라 새로운 전투 빌드와 탐험 경로를 여는 수단이 되도록 설계한다.

## 핵심 루프

탐험 → 발견 → 전투 → 보상 → 수집/성장 → 새로운 지역/던전 해금.

## V1.0 목표 규모

- 영웅 12명
- 몬스터 30종
- 보스 5종
- 마을 2곳
- 필드 4곳
- 던전 3곳
- 장비 약 80종
- 유물 약 30종
- 플레이타임 약 4~6시간

## 전투

- 실시간 탑다운 액션
- 주인공 + 동료 3명
- 기본 공격 / 특수 공격 / 회피 / 액티브 스킬
- 전투 중 캐릭터 교체
- Fire / Water / Nature / Lightning / Light / Dark 속성 체계

## 수집

- 영웅: 퀘스트, 탐험, 보스 영혼 등 게임 플레이로 해금
- 몬스터: 조우 및 처치 기록으로 도감 정보 단계적 개방
- 장비: 단순 수치 상승보다 빌드 변화를 우선
- 유물: 전투 규칙을 바꾸는 효과 중심

## 월드

연결형 세미 오픈월드 구조를 사용한다.
첫 구현 범위는 시작 마을, 왕국 평원, 고대 숲, 폐광, 고대 유적이다.

## 생활 콘텐츠

낚시, 채광, 채집, 벌목, 농사는 전투/제작/수집을 보조하는 수준으로 설계한다.
생활 콘텐츠가 메인 RPG 흐름을 방해하지 않아야 한다.

## 그래픽 원칙

- 월드 그리드: 16×16
- Native viewport: 480×270
- Integer scaling 우선
- Nearest filtering
- Sunnyside 에셋을 실제 게임 리소스로 사용
- 원본 에셋 자체를 저장소에 임의 재배포하지 않음
